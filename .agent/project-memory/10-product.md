# Product

Gremlin is a standalone generation API with a public demo site as its first client.
An Imprint replaces one character in a driving clip with the reference identity and keeps the clip's movement, poses, timing, camera, environment and interactions.
A nice-looking video that only approximates the clip from the prompt is a failure, not a cheaper Imprint.
Technical completion is not acceptance; the owner reviews real videos.
Human and animal references are both supported; a CPU detector's class label never overrides an explicit selection.
It is free and anonymous: no accounts, payments or credits; quotas and spending limits bound it.
Generated demo results are private to their creator and exist for preview only; closing the preview deletes the website’s copy.
