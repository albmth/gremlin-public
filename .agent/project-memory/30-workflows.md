# Workflows

`README.md` owns setup and the local check.
`docs/api.md` and the generated `docs/openapi.json` own the client contract; `docs/integration.md` owns client guidance and the local loop; `examples/gremlin_client.py` is the executable example.
`contract/README.md` owns the black-box suite.
`docs/engine.md` owns the pipeline, tiers, sessions and limits; `docs/model-release.md` owns the weights pin; `docs/fixtures.md` owns fixture preparation, genuine inference and review.
`docs/operations.md` and `infra/aws/README.md` own deploying and operating the API; `docs/web.md` owns the website.
`docs/privacy.md` owns retention and the data inventory.
`PLAN.md` tracks unfinished work.
